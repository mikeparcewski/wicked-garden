# Lens: competitive

**Brief line:** `Lens: competitive.` **Card:** Competitive or market analysis. **Documents:** not taken
(a staged document may still be read). **Default sources:** the web.

## What the person gets

A comparison matrix and a positioning, with every cell cited.

## Shape

1. **The field**: who is compared and why these (named in the brief, or the ones the sources show as the
   main alternatives; say which).
2. **The matrix**: one row per option, one column per dimension that matters to the question (price,
   licence, capability, scale limits, support, maturity). Every filled cell cites a claim. A cell no source
   settles reads `not found`, never a guess.
3. **Positioning**: where each option is strongest and weakest, from the matrix, cited.
4. **What would change the picture**: the cells that matter most and are least sure.
5. `## Sources`, with URLs and fetch times.

## Rules

- A vendor's own page is a source for what the vendor claims. Say "<vendor> states" for marketing claims;
  prefer independent benchmarks or documentation for capability.
- Prices and versions state their date.
- Compare like with like: the same tier, the same unit, the same date. Name any mismatch.
