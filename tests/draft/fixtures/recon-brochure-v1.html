wicked-studio

The cockpit for AI coding agents you can actually trust.

Coding agents are fast but unsupervised — wicked-studio puts a governance layer between your intent and the PR, with human gates, independent verification, and evidence for every "done."

You launch a run: describe the goal, pick which agents join, bind a repo. The agents work headless; studio watches in real time over a live WebSocket stream. When a decision matters, studio surfaces it to you — the artifact, governance findings, and controls — so you approve what counts, not what's trivial. Every run leaves a downloadable evidence bundle: transcripts, diffs, and gate outcomes. "Done" is proven, not claimed.

Three governing principles
⬡

Govern

"The evaluator is never the creator."

Every run flows through verification gates. An independent agent grades the work; you approve or redirect. Steering rules and policies codify your engineering standards once — the decisions ledger records every outcome.

  • ›Human gates: approve · steer · reject — evidence inline
  • ›Decisions ledger: full audit trail for every gate outcome
  • ›Deny-dominance enforced: the reject path is always reachable
◉

See

"Every run, in real time — nothing buried."

A live CoreEvent stream drives studio's phase timeline, evidence panel, and command-center dashboard. The portfolio KPI band shows active runs, failure count, success rate, and governed percentage — honest numbers at a glance.

  • ›Real-time phase timeline — gate events appear within 2 seconds
  • ›Downloadable evidence bundle: per-step transcripts and diffs
  • ›Portfolio dashboard: active · needs-you · success % · governed %
⊕

Direct

"Direct many projects at once. Attention comes to you."

Launch runs across repos and projects simultaneously. The command center surfaces only what needs a human — gates, failures, stalled agents — ranked by severity. Everything else works in the background.

  • ›Chat · Build · Document · Video modes per project
  • ›Multi-model fan-out: ask your whole agent roster, compare answers side by side
  • ›Cmd+K palette · desktop notifications when a run needs you

Intent

Describe the goal and choose a workflow — ask, balanced, or autonomous. The run appears in the live timeline immediately. Studio calls POST /api/v1/runs and begins streaming events.

Council

The crew engine distributes work across the agent seats you selected — Claude Code, Codex, Antigravity, or others. Each agent runs headless; studio streams live output over WebSocket.

Gates

When a phase completes, an independent evaluator grades it. A gate card surfaces within 2 s — the artifact, findings, and approve / steer / reject controls. The run advances within 3 s of your decision.

Evidence

Each completed phase appends to the evidence bundle: transcript, diff, gate outcome. The bundle is downloadable at any point — read-only; studio never writes or modifies the evidence store.

PR

With a repo bound, the run delivers its output as a pull request. The evidence bundle travels with it — the audit trail for every decision made during the run.
